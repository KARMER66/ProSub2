# PROSUB2 — Платформа подписки на профессиональное ПО с облачным хранилищем

## О проекте
**PROSUB2** — веб-сервис, позволяющий IT-специалистам (разработчикам, дизайнерам, видео-монтажерам и др.) оформлять подписку на профессиональное программное обеспечение и использовать удобное облачное хранилище.

### Основные возможности
- Каталог профессионального ПО по подписке
- Облачное хранилище с синхронизацией файлов
- Личный кабинет и управление подпиской
- Оформление и оплата подписок
- Административная панель для управления контентом

**Уровни доступа:** 3 (Посетитель → Подписчик → Администратор)

## Установка и запуск проекта

### 1. Требования к системе
- Операционная система: Windows 10/11, Linux, macOS
- Docker (рекомендуется) или:
  - Node.js 18+ (Frontend)
  - Python 3.10+ или PHP (Backend — в зависимости от реализации)
  - PostgreSQL / MySQL
  - Redis (для сессий и кэша)

### 2. Установка через Docker (рекомендуемый способ)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/yourusername/prosub2.git
cd prosub2

# 2. Запустить все сервисы
docker-compose up -d --build
```

### 3. Установка вручную

#### Backend
```bash
cd backend
pip install -r requirements.txt    # или npm install
cp .env.example .env
# Настроить подключение к БД в .env
python manage.py migrate
python manage.py runserver
```

#### Frontend
```bash
cd frontend
npm install
npm run dev
```

### 4. Доступ к приложению
- Главная страница: `http://localhost:3000`
- Админ-панель: `http://localhost:3000/admin` (логин/пароль указан в документации)

### 5. Инсталлятор
Файл `PROSUB2_Setup.msi` — готовый установщик для Windows.  
Запустите его и следуйте инструкциям мастера установки.
